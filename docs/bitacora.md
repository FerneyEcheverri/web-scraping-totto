# Bitácora del proyecto Web Scraping Totto

## Información general
Proyecto académico de Web Scraping sobre Totto Colombia.

## Herramientas utilizadas
- Google Colab
- Python
- Requests
- BeautifulSoup
- Pandas
- Git
- GitHub
- GitHub Actions (CI/CD)

## Actividad 1: Configuración inicial
- Se creó el repositorio en GitHub.
- Se conectó Google Colab con GitHub.
- Se descargó el repositorio en Colab.
- Se verificó la conexión con el repositorio remoto.

## Actividad 2: Integración y Entrega Continua (CI/CD)
- Creación de pruebas unitarias automatizadas para validar la integridad del notebook.
- Configuración de un flujo de trabajo (workflow) en GitHub Actions (`ci.yml`).
- Implementación de la fase de pruebas automáticas (CI) con Python 3.11.
- Configuración de la fase de empaquetado de entregables (CD) como artefactos del proyecto.
