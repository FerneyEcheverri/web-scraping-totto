SOBRE EL PROYECTO

De los datos al análisis

Este proyecto utiliza técnicas de Web Scraping con Python para recopilar información pública del catálogo de Totto Colombia. Los datos se organizan y procesan para facilitar el análisis comparativo de los morrales ejecutivos.
